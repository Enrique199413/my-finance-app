# Verify Build Integrity

Whenever you make changes to the source code (React components, TypeScript files, configurations, etc.) in this project, you MUST verify the integrity of the build before finishing your task.

To do this, always run:
`npm run build`

If the build fails or reports TypeScript/Vite errors, you must fix the errors before concluding your task. Do not ask the user for permission to fix compilation errors you introduced; just fix them.
